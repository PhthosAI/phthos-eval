# Phthos Eval

Open-source agent evaluation engine. Self-host. Bring your own model key for optional LLM judges.

- Score agent trajectories (tools, cost, policy), not just the last message.
- Same scorers offline (CI) and live (sampled production).
- Output is a diagnosis artifact another system can read. This repo does **not** apply fixes or charge you.

Local path: `d:\Projects\phthos-eval\public`

Hosted billing/SSO is a separate private product. User-facing docs for install/run will live here when the spike exists.
